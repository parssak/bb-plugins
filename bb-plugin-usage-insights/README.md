# Usage insights

Usage insights tracks Codex allowance history and consumption since local midnight. It appears in plugin settings and a sidebar footer disclosure. A manual reset forecast queries codex-reset.com. BB’s Provider usage plugin remains available for standard quota displays. History can be imported from the combined Threadflow plugin.

```sh
npm ci
npm run check
npm test
bb plugin build .
bb plugin install .
```

See the repository README for the one-time storage import.
